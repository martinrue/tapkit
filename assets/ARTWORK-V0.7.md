# Tapkit 0.7 artwork prompts

Generated with the built-in `image_gen` tool, using true transparent alpha. Final project assets: `assets/art/{theme}-{handpan,tambourine}.png`. Existing white drum hands are reused for both; Cartoon uses the existing illustrated white drum hands. No new runtime dependencies.

Classic uses the Djembe sprite as a material reference only. The other styles edit the classic instrument while preserving its silhouette, camera, scale, margins, and note-field/jingle positions. Each variant was a separate built-in image generation call.
